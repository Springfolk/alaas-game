# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful, to each other and to the culture the museum shows: Sakha traditions are living ones.
- Disagree about facts with sources, not with people.
- No harassment, insults or discrimination of any kind.

Report a problem to hello@springfolk.co. Reports are read by the maintainer and kept private.
