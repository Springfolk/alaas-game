# Architecture

| Path | Role |
|---|---|
| `src/main.js` | `Game`: boot, title, frame loop, focus (raycast ≤3.4 m or zone), do → act, put down, E → inspect stage → its text → close (`docs/interactions.md`), save |
| `src/interact/*` | Hands-on acts: carrying (pail, tools, an armful of firewood), sitting, berries; `work/` = jobs done with a tool (`docs/interactions.md`); props in `src/models/chores.js`, `work.js` |
| `src/engine/engine.js` | `Engine`: WebGPURenderer, `SunLight` (cascades, cloud shadows from the sky's cloud field via a 512² `cloudMap` re-rendered 4×/s or on a texel move — every frame was ~30% of a phone frame's GPU), sun intensity by air mass, PMREM sky env (intensity 1: sky and sun share absolute units), aerial haze (`scene.fogNode`: horizon colour + forward-scatter lobe toward the sun), metered eye adaptation |
| `src/engine/sky.js` | Perez/Preetham clear sky (T 1.9) in scene units, cumulus layer at 1.8 km (`cloudField`, shared with cloud shadows), sunlit ground below the horizon (green env bounce); `updateSky` on CPU gives haze colours |
| `src/engine/merge.js` · `lod.js` | Applied by `world.js` after the homestead (`world.optimized`; `?nomerge` = A/B off): merged depth-only shadow proxy per model and side (layer 2, cascade cameras only; a lone mesh too when over 20k triangles, for its simplified copy); billboard impostors per cluster (8 azimuths baked in place into an atlas, one instanced draw, also stand in for the models in the lake mirror away from the shore) that replace a cluster's meshes beyond ~110 m; meshes under ~2.5 px move to layer 30. Kept out: act/take targets, `userData.dynamic`; a watchdog gives a merged part that moves its own shadow back (and warns) |
| `src/engine/pacing.js` | Frame pacing and dynamic quality as plain functions over the engine's state (no three): `pace`, `govern`, `frameDone`, `KNOBS`; `tools/pace-sim.mjs` runs them against a modelled device |
| `src/engine/post.js` | GTAO (high; its pre-pass feeds only the AO) × interior occlusion → TRAA (velocity and depth from the scene pass it resolves, every tier: the pre-pass's smeared every pan) → clamped sharpen (0.8) → capped-input glare (off on low) → AgX with a look (power/saturation) → vignette, grain; 64×36 log-luminance meter read back every 0.15 s. No TRAA (phones): no sharpen taps, FXAA reads the graded image from 8 bits |
| `src/engine/interiors.js` | Analytic sky occlusion inside urasa/balagan(+khoton)/ampaar from `layout.js` placements (all tiers; models placed elsewhere, e.g. the viewer, get none) |
| `src/engine/materials.js` | `pbr(id)` / `maps(id)` / `tex()` for the CC0 sets in `public/assets/tex/<id>/` (diff, nor, arm) |
| `src/engine/master.js` | Master materials (same-shape graphs share one build), the homestead light set (`docs/materials.md`) |
| `src/world/terrain.js` | Pure height/forest/splat functions: the alaas hollow, lake, homestead pads |
| `src/world/ground.js` | Warped ground grid (~1.5 m cells at the homestead → ~40 m at the horizon) + splat material |
| `src/load/*` | Loading: shader streaming behind the title, load-time workers (`docs/loading.md`) |
| `src/world/layout.js` | Placements of every model (single source of truth), start spot |
| `src/world/world.js` | Builds terrain, models (`src/models/*.js`), nature (`src/nature/*.js`); colliders, floors, interactables, updaters |
| `src/models/*.js` | One module per placed thing (contract: `docs/models.md`) |
| `src/nature/*.js` | `default (ctx, world)`, auto-loaded after the models: `forest.js` + `trees/` (procedural larch/birch/pine taiga: generator, wind/LOD-dither materials, baked impostors, canopy band, deadwood; textures from `tools/gen-forest-tex.mjs`; `?trees`, `?noforest`), `grass.js` (blade grass, flowers, shore plants; `natureField`/`natureWind` shared fields), `lake.js` (planar-reflection water), `life.js` + `life/` (birds, insects/leaves, midges/fluff/dust motes, lake ripples/striders: 4 draws, GPU- or CPU-steered, follow `natureWind`; debug `world.life`) |
| `src/audio/audio.js` | `AudioScape`: ambience beds, 3D one-shots, footsteps, named action sounds |
| `src/ui/stage.js` | The inspect stage's camera: the game's own view goes to the thing (`docs/ui.md`); views per entry in `src/data/views.json` |
| `src/ui/ui.js` · `src/ui/i18n.js` | Prompt, the stage's type and photographs (`src/data/images.json`), journal, toasts, title loading bar (title also: Springfolk mark top-left, links row with version, GitHub, credits and the "open a ticket" call; pause: About tab with the same links and the licence line) · interface strings and the controls list; Sakha/English/Russian (L cycles) |
| `index.html` · `public/assets/ui/` | All interface styles (`docs/ui.md`; the Aero `.glass` frame only on the pause menu, light `.client`, glossy `.btn`) · self-hosted Open Sans + Noto Serif (`fonts.css`) |
| `src/data/entries.json` | Explainer entries (Sakha + English) with sources and confidence |
| `src/player.js` · `src/input.js` | Body: momentum walk 10:00/run (Shift) 5:30 min/km/crouch (C), jump (Space) with gather + landing spring, vault over 0.3–1.3 m obstacles (rays onto the contact collider's midline), wall sliding, footfall-synced bob/sway/roll, strafe lean, run FOV kick · keys/mouse, or touch (`active` = locked or touch live) |
| `src/util.js` | Shared helpers: seeded random (`mulberry32`, `hash2`), value noise/`fbm`, `clamp`/`lerp`/`smooth`/`ease`/`damp`, yaw vectors, `urlFlag` (debug query switches) |
| `src/ui/touch.js` | Phone controls (auto on coarse pointers; `?touch` / `?notouch`): stick fixed bottom left (safe-area insets; its place in the CSS), driven only by a touch starting ≤100 px from its middle (rim = run); a touch starting anywhere else on the view (the canvas: not windows, toasts or buttons) looks, short tap = do (or the card) on the thing in focus; one walk + one look touch at once; "Look around" tip until the first look drag (hidden under a card); buttons (no blur) hand (held; drags look) / eye / put down / jump / crouch / journal / pause, over a card or the journal language / close; `tc-` scoped CSS |

- North is −Z, east +X; models face east (+X) locally — Sakha doors face east.
- Eye adaptation (`Engine.update`): `closeLook` = full adaptation up to 24× (a thing held up to the eye in a dark corner), `adaptFast` (s) = at once (after a cut of the view); both set by the stage.
- Player settings (`player.settings`, saved in `alaas-v1` settings): `sens`, `invertY`, `fov` (base; run adds ≤7.5°), `motion` 0–1 (camera motion comfort: bob, sway, roll, FOV kick; 0 = steady), `smooth` 0–1 (mouse-look smoothing; touch always has 0.3 for the finger's one-pixel steps, let go as the view falls behind: a drag of some speed is followed at once, it trailed ~10 ms). `main.js` binds `#s-motion` / `#s-smooth` sliders if present.
- Player yaw 0 looks −Z; `util.js` has `fwd*/right*/yawTo`.
- Ground height: `world.groundAt()` (knows floors), not `terrain.height()`.
- Camera layer 1 = near grass, grass ring, flowers, near trees: the lake reflection and the shadow cascades skip it. Layer 2 = shadow proxies, 30 = culled (merge.js); the loader's collect pass (camera on all layers) builds both.
- Culling beyond three's per-object frustum test: the forest's near/mid instance lists keep only trees in the view cone (half-FOV + margin), within 12 m, or whose shadow tip lands in it; a turn past ~11° refills before that frame's render. Full trees (lod0) to 34 m (was 44). Grass/flower chunks wholly outside their ring (corners past `rOut`/`R`, the mid ring's hole) are hidden; far chunks draw a coarser blade index (near from 11 m: 3 triangles, was 5; mid from 30 m: 1, was 3; `bladeGeometry` `userData.lite`). The ground draws as 4×4 tiles (root: one corner triangle; the lake mirror swaps tiles for the coarse copy).
- Per-frame garbage (WebKit pauses 40–70 ms to collect it every ~20–40 s): the shadow pass's shared material no longer bumps `version` per caster (`src/load/shadows.js`: every shadow render object rebuilt its key string each frame); the urasa curtain computes its own normals and drapes only within 30 m; no per-tree closures/arrays in the forest refresh. ~1.4 → ~0.58 → ~0.41 MB/frame (Chrome sampling); most of the rest is three's per-draw bookkeeping (`Bindings._update` key strings), so fewer draws = fewer pauses. Shadow proxies are simplified in a load worker (`src/load/simplify.js`, meshoptimizer, 1.5 cm absolute error + pruning: urasa 114k → 19k triangles); `?fullshadow` = exact (A/B), `?keyart` always exact.
## Performance rules
- Device tiers (`src/engine/tier.js`): `high` (GTAO pre-pass, px ratio up to 2 = native on Retina) · `medium` (one scene pass, colour+velocity MRT, up to 1.5) · `low` (0.75 px ratio, 1024 shadows, 1k textures, no lake mirror) · `mobile` (WebGPU where the browser has it, like every tier; WebGL2 only without an adapter or `?webgl`; lazy sun shadows (re-rendered on a 1.5 m move / 8° turn, ≤8/s, else every 2 s (`?nolazy`: A/B; the warm-up forces them each round)); anisotropy ≤4; house impostors from max(45 m, 3×size) (desktop 110 m; the homestead atlas full size); 30 fps; 67–100% of the screen's resolution, lite too (starts at 67%, climbs while frames keep pace); no TRAA or sharpen (its jitter and history blend shimmered and softened the still view at 30 fps) but FXAA on the graded image; `?taa`/`?notaa`/`?noaa` override, 1024 shadows, 512 textures, 1024 impostor atlases, sparser ground/forest). Settings "Auto" (default) detects: touch device → mobile, + `LITE` (256 textures, 512 shadows/atlases, sparser grass/forest) when ≤3 GB or <4 cores; no WebGPU, <6 cores, <4 GB or pre-Xe Intel → low; else medium (never high). Change needs a reload.
- Phone memory (iOS kills a tab past ~1–1.5 GB: Safari reloads, then "A problem repeatedly occurred"): decided up front, it can't be handed back. `TIER.release` closes each texture image once uploaded (WebKit keeps ImageBitmaps as IOSurfaces), ≤3 load workers, ≤`TIER.pipelines` compiles in flight (4, lite 2). Every tier: `src/load/release.js` drops the JS copy of vertex data the GPU holds (built and again after the warm-up; phone ~48 MB) and geocache drops each decoded pack once read; attributes rewritten in play must be `DynamicDrawUsage` (dev warns on a freed one), raycast meshes keep positions + index; `?keepgeo` = off (A/B). JS heap: `src/load/stream.js` empties each three `NodeBuilder` once its state is taken (three's own uniform callbacks keep every builder alive: ~110 after a load; phone tier heap 261 → 129 MB in dev Chrome); `?keepbuilders` = off (A/B).
- Boot guard (`tier.js` `bootStep`): a load marks `localStorage['alaas-boot5']` until ready or pagehide; an unfinished mark (OS-killed load; a hidden page is unmarked) or a "failed to start" (`bootFailed`) steps Auto down to mobile+LITE / low (never to WebGL2); a load that finished there tries the full tier next time, at most once a day. A phone that reports no memory (Safari) starts at the step-down and tries the full tier on its next load. Choosing a quality resets it. A lost GPU device (while loading or in play: iOS: the canvas froze; Safari can also break a device without losing it, so the first `createCommandEncoder` throw counts; or 5 thrown frames within 3 s) is restored by `restoreLost`: a reload at the same tier and backend where the player stood (`resumeSpot`), once the page is visible; 3 losses within 2 min in a tab → WebGL2 for that tab's session. A load error on a broken device (`Engine.deviceBroken`: a new buffer maps 0 bytes; iOS reloads did that while the old page still held the GPU) counts as a loss, not a failed start; `pagehide` (not into the back-forward cache) destroys the device.
- Read the tier from `engine.tier` (`high|medium|low|mobile`) or `TIER` (`tier.js`, set before the world builds): `grassDensity` (1 / 1 / 0.6 / 0.45), `forest` (ring-radius scale), `ground` (grid verts), `texMax`, `lite`. `engine.opts.quality` stays `high|medium|low` (mobile → `low`).
- Textures (`materials.js` `tex()`) load as ImageBitmaps off the main thread, pre-flipped (`flipY = false`), scaled down to `TIER.texMax` (`capFor`: `arm` maps at half of it, on `low` the normal maps too, `high` all full; GPU textures low 641 → 428 MB, mobile 296 → 257, medium 978 → 919); the ground's splat sets are packed in a worker.
- Frame pacing (`Game.tick` → `Engine.pace`, `src/engine/pacing.js`): a steady 60 everywhere (title, menus, cards, idle); 30 with the battery saver (default on phones, since at 60 an iPhone overheated and throttled within a minute, and where the Battery Status API reports ≤20% unplugged; the setting overrides). `pace` draws every n-th display refresh (120 Hz → every 2nd; refresh rates 60 doesn't divide run at their own rate, or 72 at 144 Hz), counted on the display's own clock from the last drawn frame: the refresh interval is the sum of 31 rAF deltas over the refreshes they span, so timestamp jitter and late callbacks do not shift the beat. `frame(now)` steps time by the rAF timestamp. No frames once the pause menu has settled.
- Dynamic quality (`govern` in `pacing.js`, every ~0.5 s of frames; rule and thresholds in its header): it reads late frames (a display refresh late or more), the frame's JS time and when the GPU finishes each frame (`Engine.frameDone`: the queue's promise on WebGPU, a fence on WebGL2; Safari's WebGL2 waits ~5 ms a frame in the fence, so where the first 30 cost over 1 ms each it goes without, by late frames alone). Over (late frames, or the GPU two frames behind): fewer pixels, 5–20% a step, down to the tier's floor (`resMin`: high 1 · medium 0.7 · low 0.5 · mobile and lite 67% of the screen; never under half the screen's own ratio, `MIN_RES`); at the floor, or when the JS alone is the limit, `KNOBS` one at a time: shadow range ×0.7 → lake mirror ×0.6 → a slower beat (one more refresh per frame: 60 → 30, 120 Hz 60 → 40 → 30; phones 30 → 20), none builds a shader. Room (the GPU done within 0.8 of the interval, no late frame): 4–8% more pixels, a slower beat back first (when the GPU's time, scaled to the floor resolution by the share of it the last two scales showed to be pixels, fits the faster one), the other knobs at full resolution. Otherwise nothing: a rate held with little to spare is not probed. `pace` also holds a frame back while the GPU still has three (Chrome queues 3–4 before it slows rAF). F3 shows `res` as % of native, the knobs on and the GPU's ms.
- Why (headless Chrome, GPU made the limit: `q=high` at 5120×2880): the old rule (average interval ≥ 12% over → −8/15%; all on time → +10%, retried every 8 s) hunted between 63 and 83%, 142 late frames in 45 s and 3–4 frames queued (GPU 18 ms median, 80 ms p95 behind the JS); now 50–62%, 3 late frames, 10 ms median. With the CPU ×4 (JS 15.7 ms a frame): 42 late frames in 40 s at "60" → a steady 30, none.
- `node tools/bench.mjs [chrome|webkit|phone] [query]` — uncapped CPU ms, fps, calls, triangles at five views (`PORT`). `node tools/hitch.mjs …`: 1.2 km walk with mouse look through every area at real pacing: frame-interval p50/p95/p99/max, hitches, pipelines compiled after the fade (`UNCAPPED=1`).
- Lake mirror: model parts whose reflected sight line misses the water, or under ~3 reflection px, are hidden for that pass (`lake.js`).
- `low`/`mobile` (`reflection: 0`): no mirror pass; the water samples the sky PMREM along the reflected ray, a dark band under ~8° for the treeline. Ground there: normal maps at one tiling scale (5 of 21 samples). Every tier: the ground's cow-pat noises run only inside a pat's cell, its 25–110 m noises per vertex.
- `low`/`mobile` (`leanEnv`, `src/engine/leanenv.js`; `?fullenv` A/B): the sky PMREM is baked on each `setSun` into two 64×32 equirect panoramas (roughness 0.5, 1); lit pixels read those instead of four cube-UV lookups.
- Phones (iPhone 14 Pro, `tools/iphone.mjs`): on WebGL2 a frame costs ~0.15–0.2 ms per draw call and the phone sits in a slow state (~45 ms at the urasa; a fast ~17 ms one lasts seconds after an idle); the same view on WebGPU holds 17 ms, so phones use WebGPU (2 min of play: 30 fps held, resolution climbing from 67%). Cuts: no mid grass ring (the ground's meadow tint from 11 m), near blades ~half (wider, coarse from 6 m), flowers ~half (`grass.js` `phone`); ground grid 320, a splat set sampled only where it shows (`ground.js` `lean`, textureGrad); model fractal noise two octaves fewer (`tier.js` `octaves`), the urasa cover's six slow noises per vertex (`urasa/mats.js`); smoke 45% of the puffs (`yardlife/smoke.js`). Balagan plaster: the logs under flaked patches only inside them (branch); trodden earth: slow noises per vertex; forest: every tree in the outer rows, every other one deeper in (`forest.js` `thin`). Low/phones: the balagans' roof plants cast no shadow. Every tier: shore plants zero-area beyond 110 m, a sector wholly beyond it hidden; urasa hides one noise for the skin's kind (was four); trodden hoof prints by cell hash.
- Uploads per frame (`Engine.init`, three r186 internals: recheck on upgrade; `?reupload` = three's own, A/B): a `DynamicDrawUsage` attribute goes up only when marked (`needsUpdate`), not on every frame it is drawn (the forest's instance lists were 2.1 MB a frame); instance matrices live in instanced vertex buffers, not three's per-frame uniform buffers (0.5 MB a frame of unchanged matrices). So code that rewrites an attribute must set `needsUpdate`. World matrices are updated once a frame (`Engine.render`), not once per pass. Yard, medium, M3 Max: buffer writes 2107 → 37 kB a frame, frame JS 5.2 → 4.3 ms, uncapped frame 5.1 → 4.1 ms.
- Draw order (`world.js`): the homestead's cut-out materials (`alphaTest`: plaster, nets, the birch curtain) get `renderOrder` 1, after the plain opaque ones, so pixels of theirs behind a wall are skipped before shading (inside the balagan looking east, medium at 2592×1675 on an M3 Max: 15.0 → 5.5 ms a frame; phone tier 4.6 → 2.2; high 31.6 → 16.7). An expensive cut-out material on a model: leave its `renderOrder` at 0 for this.
- Smoke (`yardlife/smoke.js`; every puff is a blended layer): its noise is two lookups of a baked texture, and a puff the eye is inside of thins to nothing and is not drawn (the smudge fire at the pen, medium at 2592×1675 on an M3 Max: 36 → 13 ms a frame, worst 66 → 15).
- Frame step: dt capped at 0.25 s (was 0.05: under 20 fps the world ran slow); the player steps ≤1/30 s (`Game.stepPlayer`), look input once.
- Never add/remove lights or toggle `light.visible` at runtime — the light set is part of every material's shader, so it recompiles everything (multi-second freeze). Animate `intensity` instead.
- Light sets (`world.js`, `src/engine/master.js`): nature gets `lights([sun])`; every model the homestead set (sun + two local lights read from each material: its own model's fires), so no fire shines through other walls and builds don't split by set (`docs/materials.md`).
- Meadow blades are two-sided towards the sun: a face turned from it is mirrored across the sun's vertical plane, so the sward lights the same looking towards or away from the sun (plus a back-glow emissive). Flowers and shore plants transmit backlight instead (`LeafLighting` in `grass.js`). Paths are trodden sward (sparse 3–10 cm blades) over pale dusty earth (`ground.js`, yardlife decals).
- A material that builds its vertices in `positionNode` must also `positionPrevious.assign(<built position>)`, or TRAA gets wrong velocity, drops its history and the mesh aliases/shimmers (grass, trees, impostors and life layers do).
- The grass mask can be rewritten in play: `world._field.mask.mow(minX, minZ, maxX, maxZ, inside)` (mowing), `mask.tall(x, z)`; blades and ground read it every frame, nothing rebuilds.
- Grass blades never go under ~1.3–1.6 px wide (`natureWind.px`): far blades widen and thin out by the same factor; shading (normals, AO, colour variance) flattens with distance; `BladeMaterial` has weak specular and no grazing Fresnel. Phones/`low` tier (`engine.tier` or the quality preset) draw half the near blades.
- Every shader is built while loading, in time slices behind a live view of the world, and `Game.warmUp()` collects what is out of view; nothing compiles after "click to walk" (`docs/loading.md`).
- Look-at raycast runs every 3rd frame and only against targets whose bounds are within reach; target meshes over 1500 triangles test only the triangles near the ray (`src/interact/raycast.js`: a 16³ grid per geometry, built in idle moments; beside the ampaar's logs a pick took 2.6 ms and left 2.4 MB of garbage, now < 0.1 ms).
- Texture limit: 16 sampled textures per shader stage on WebGPU — the ground splat shares maps carefully.
## UI API (`game.ui`)
- `showEntry(id, { mode: 'peek'|'full', kind })` — the stage's interface (`docs/ui.md`; `game.read` opens stage and card together); `close()`; `open` = `'card'|'journal'|null`, `isOpen`, `modal`, `mode`, `current`.
- `scroll(dy)`; `setImage(i)` a photograph beside the thing; `enlarge()`; `layout()` → `stage.area`; `frame()` moves the names on the stage.
- `toast(html, ms)` — a saying as a caption (`<b>` + `<small>`); `discovered(id)` — the found thing's picture and name by the corner; `setPrompt(label, action, { act, read })`.
- Title bar progress is read from `#go`'s text (`N%` build → `… N%` warm-up); `#title.ready` once `game.ready`.
- Settings ids → `save.settings`: `s-motion` `motion`, `s-smooth` `smooth`, `s-battery` `batterySaver`, `s-q` `quality` (auto/high/medium/low/mobile).
